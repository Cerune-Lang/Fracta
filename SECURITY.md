# Security Policy / セキュリティポリシー

Fracta is an experimental research repository, not a production security guarantee.

未修正の脆弱性、悪用可能な再現例、機密情報は公開 Issue / PR に投稿しないでください。

For suspected Cerune language/compiler vulnerabilities, use the private vulnerability reporting flow on [Cerune](https://github.com/Cerune-Lang/Cerune/security/advisories/new) where available. If the private reporting flow is unavailable, avoid public disclosure and contact maintainers through an approved private channel.

Please include the affected version/commit, environment, a minimal reproducer, and observed versus expected behavior. Public regression cases should only be added after coordinated disclosure or mitigation.
