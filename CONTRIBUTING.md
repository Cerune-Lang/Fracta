# Contributing / コントリビューション

- Only test systems you own or are authorized to test. / 許可された環境だけで検証してください。
- Keep samples minimal, deterministic, and locally reproducible. / 最小限で再現可能なケースを投稿してください。
- Record Cerune version/commit, target platform, command, expected result, and actual result.
- Distinguish expected runtime traps from security vulnerabilities.
- Never publish unpatched vulnerabilities or exploitable details. Follow [SECURITY.md](SECURITY.md).
- Prefer sample names describing the tested behavior, not unverified CVE/CWE claims.
